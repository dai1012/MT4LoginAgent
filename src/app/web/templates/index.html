/mt4 status

WINDOWS ACCEPTANCE

Windows Test

安全优先：默认只执行 SAFE 检查；Real Login、Group 和 Full Slack E2E 需要明确确认。

Phase 1 — Environment / Safe Checks

不需要 OTP；检查 Windows、Python、pywinauto、data-dir、Web、配置和 Account 静态完整性。

Phase 2 — MT4 Discovery / UIA

不输入 OTP；枚举进程和 UIA 候选控件。不会自动修改正式 Account。

Phase 3 — Slack Safe Tests

不会向真实 Slack 发送测试消息；真实命令会显示 ACTION REQUIRED。

Phase 4 — Real Login（必须人工确认）

REAL ACCOUNT ACTION：这会尝试登录选中的 Rakuten MT4。OTP 只在内存中使用，不进入报告、日志或 History。
