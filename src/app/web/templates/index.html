COMMAND CHANNEL

Slack Socket Mode

Token 只写入本机 secrets 文件，页面不会回显原值。

Allowed 决定谁能用 Agent；Account 绑定决定这个人能操作哪些 alias。没有绑定任何账号的用户显示“no accounts assigned”，将不能操作任何账号（fail-closed，不是全部账号）。只显示 alias，不显示 Login ID 与凭据。

网络边界：此 Agent 只需要连接 Slack 官方 Socket Mode/API；MT4 使用其原有网络连接。没有 telemetry、analytics 或 AI API。

Slack 命令

/mt4 A 123456
/mt4 GROUP1 123456
/mt4 status

只有 Allowed Slack User IDs 中的 User ID 可以执行登录。未授权请求会在解析 OTP 前拒绝。

WINDOWS ACCEPTANCE

Windows Test

安全优先：默认只执行 SAFE 检查；Real Login、Group 和 Full Slack E2E 需要明确确认。

Phase 1 — Environment / Safe Checks

不需要 OTP；检查 Windows、Python、pywinauto、data-dir、Web、配置和 Account 静态完整性。

Phase 2 — MT4 Discovery / UIA

不输入 OTP；枚举进程和 UIA 候选控件。不会自动修改正式 Account。

Detect Win32 only reads the login dialog and changes nothing by itself. Nothing is saved until a human applies. The inspection never reads the credential field.

Phase 3 — Slack Safe Tests

不会向真实 Slack 发送测试消息；真实命令会显示 ACTION REQUIRED。

Phase 4 — Real Login（必须人工确认）

REAL ACCOUNT ACTION：这会尝试登录选中的 Rakuten MT4。开始前请人工确认 Rakuten 当前不处于已知 maintenance/offline 时段；当前没有 broker preflight。OTP 只在内存中使用，不进入报告、日志或 History。
